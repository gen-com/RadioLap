# 레이스 상세 화면 상태와 동작

[기능 목적](../README.md)과 [UseCase 계약](UseCaseContract.md)을 바탕으로 표시 상태·선택·조회 생명주기를 정의합니다. 문서의 동작 합의와 실제 화면 구현·검증 상태는 구분합니다.

## 책임과 입력

ViewModel은 생성 시 목록에서 선택한 Race와 UseCase를 받고, 화면 수명 동안 같은 Race를 사용합니다. 이 Race를 UseCase에 전달해 참가자·결과 조회를 요청하고 결과 유효성·화면 상태·표시 그룹과 순서를 관리합니다. 외부 응답 해석이나 UseCase의 정규화·중복 처리를 반복하지 않습니다.

View는 상태에 따라 배치·날짜·대체 문구를 표시하고 이벤트를 전달하며 화면 이동과 스크롤 위치를 관리합니다. 의존성 조립은 화면 밖에서 Repository를 UseCase에, UseCase를 소비자에게 제공합니다. 목록의 계층이나 타입을 기계적으로 복제하지 않습니다.

## 공개 인터페이스

View가 사용하는 상태·동작 계약은 RaceDetailPresentation이며 RaceDetailViewModel이 구현합니다. 다음 선언은 합의한 인터페이스로, 코드 구현·검증 완료를 뜻하지 않습니다.

```swift
@MainActor
protocol RaceDetailPresentation: AnyObject, Observable {
    var race: Race { get }
    var state: RaceDetailState { get }

    func load()
    func cancel()
}
```

ViewModel은 init(race: Race, useCase: any RaceDetailUseCase)로 생성합니다. race와 state는 외부에서 읽기만 가능하며, 초기 state는 idle입니다. 드라이버 선택과 화면 이동은 View가 담당하므로 별도의 ViewModel 선택 메서드는 두지 않습니다.

```swift
enum RaceDetailState: Equatable {
    case idle
    case loading
    case content([RaceDriverGroup])
    case empty
    case failed
    case cancelled
}

struct RaceDriverGroup: Equatable {
    let kind: Kind
    let drivers: [RaceDriver]

    enum Kind: Equatable {
        case ranked
        case unranked
        case resultsUnavailable
    }
}
```

RaceDetailState와 RaceDriverGroup은 Presentation 모델입니다. content는 참가자가 있는 성공 결과이며, 빈 참가자 결과는 empty로 표현합니다. 그룹 구성과 순서는 아래 ‘드라이버 그룹과 표시’ 기준을 따릅니다.

## 표시 상태

레이스 기본 정보는 최초 진입부터 모든 상태에서 표시합니다. state는 드라이버 영역의 표시를 결정합니다.

| 상태 | 드라이버 영역의 표시와 동작 |
| --- | --- |
| idle — 최초 조회 전 | 첫 참가자·결과 조회를 시작할 준비 상태 |
| loading — 조회 중 | 로딩 표시 |
| content — 조회 성공 | 드라이버 그룹 표시 |
| empty — 참가자 없는 정상 성공 | “참가 드라이버 정보가 없습니다” 표시 |
| failed — 조회 실패 | “레이스 정보를 불러오지 못했습니다.”와 ‘다시 시도’ 버튼 표시 |
| cancelled — 조회 취소 | 오류 안내 없이 ‘다시 불러오기’ 버튼 표시 |

모든 상태에서 목록으로 돌아갈 수 있습니다. 참가자·결과 조회 실패를 부분 성공이나 정상 빈 참가자로 표시하지 않습니다. 실패 안내는 고정 문구이며 내부 오류 종류로 화면을 분기하지 않습니다.

## 조회·재시도·취소

- 목록에서 상세로 처음 진입하면 화면이 load()를 한 번 호출합니다. 초기화 자체는 조회하지 않습니다.
- load()는 모든 상태에서 기존 요청을 취소·무효화하고 즉시 loading으로 전환하여 같은 Race로 새 조회를 시작합니다. 응답을 기다리지 않고 반환하며 결과는 state로 제공합니다.
- 실패 후 ‘다시 시도’와 취소 후 ‘다시 불러오기’는 load()를 호출합니다. 취소 후 자동 재요청은 하지 않습니다.
- 마지막 유효 요청만 결과를 반영합니다. 이전 요청의 늦은 성공·실패·취소는 현재 상태를 변경하지 않으며, 요청 교체로 발생한 취소도 cancelled로 표시하지 않습니다.
- 현재 유효 요청이 CancellationError로 끝나면 cancelled로 전환합니다.
- 상세를 떠날 때 cancel()을 호출합니다. 진행 중인 요청이 있으면 취소·무효화하고 즉시 cancelled로 전환합니다. 진행 중인 요청이 없으면 성공 결과·실패 안내를 포함한 현재 상태를 유지합니다.

## 레이스 정보

전달받은 Race의 시즌·대회 이름·결승 시작 날짜·장소와 결승 표시를 제공합니다. 날짜는 기기 시간대를 적용하며 시각은 표시하지 않습니다. 시즌을 날짜의 연도에서 계산하지 않습니다. 기본 정보는 목록에서 받은 값을 사용하며 다시 조회하거나 정규화하지 않습니다. 참가자·결과 조회와 재시도에는 race.sessionID를 사용합니다.

장소가 없으면 ‘장소 정보 없음’을 표시합니다. 시간대 변경 후 날짜를 다시 표시할 때 원본 절대 시각과 드라이버 순서는 유지합니다. 시간대 변경만으로 데이터를 재조회하지 않습니다.

## 드라이버 그룹과 표시

| 표시 순서 | 대상 | 그룹 내 순서 |
| --- | --- | --- |
| 1 | 결과와 순위가 있는 드라이버 | 순위 오름차순, 동률은 드라이버 번호 오름차순 |
| 2 — 순위 없음 | 결과는 있으나 순위가 없는 드라이버 | 드라이버 번호 오름차순 |
| 3 — 결과 미제공 | 결과 레코드가 없는 드라이버 | 드라이버 번호 오름차순 |

빈 그룹은 표시하지 않습니다. 결과 미제공 그룹에는 “아직 결과가 제공되지 않았습니다”라고 안내합니다. 이는 현재 자료의 부재를 뜻하며 향후 제공을 보장하거나 부재 사유를 단정하지 않습니다.

전체 인원수는 그룹별 참가자 수의 합이며 결과 미제공 참가자를 포함합니다. 그룹 인원수는 해당 그룹의 참가자 수입니다. 인원수는 배열에서 계산하고 별도로 저장하지 않습니다. 예시 인원수·순위·날짜를 고정하지 않습니다.

- 드라이버 이름·약칭·팀 이름과 제공된 순위·경기 상태를 표시합니다.
- 약칭이 없으면 약칭 영역을 숨기고 이름을 유지합니다. 팀 이름이 없으면 ‘팀 정보 없음’을 표시합니다.
- true인 상태는 모두 ‘DNF · 미완주’, ‘DNS · 미출발’, ‘DSQ · 실격’으로 표시합니다. 모두 false여도 완주를 추정하지 않습니다.
- 상태 때문에 순위를 지우거나 전용 그룹으로 옮기지 않습니다. 순위 공백과 동률은 제공된 값대로 유지합니다.
- 공개 라디오 개수 표시는 보류합니다. 조회하지 않은 상태를 0개나 ‘공개 라디오 없음’으로 표시하지 않습니다.

## 선택과 복귀

모든 그룹의 드라이버를 선택할 수 있습니다. 순위 없음·DNF·DNS·DSQ·결과 미제공으로 선택을 막지 않습니다. 다음 라디오 화면에는 Race와 선택한 RaceDriver를 전달하며 식별에는 race.sessionID와 driver.driverNumber를 사용합니다. 이름·순위로 식별하지 않습니다. 조회·재생은 라디오 기능의 책임이며 상세는 해당 기능의 Component를 주입해 목적지를 연결합니다.

- 라디오 화면에서 상세로 돌아오면 기존 결과와 보던 스크롤 위치를 유지하고 재조회하지 않습니다.
- 상세에서 목록으로 돌아오면 목록의 기존 목록과 스크롤 위치를 유지하고 재조회하지 않습니다. 목록의 기존 계약을 따릅니다.
- 목록으로 돌아간 뒤 레이스를 다시 선택하면 새 상세 조회를 시작합니다.

## 검증 경계

ViewModel은 UseCase 대역으로 상태·요청 입력·재시도·무효 응답 차단·그룹 구성과 정렬을 확인합니다. 화면 배치·안내·선택·복귀와 스크롤 보존은 직접 화면 검증이 필요합니다. 코드나 테스트의 존재만으로 해당 검증이 완료된 것으로 표시하지 않습니다.
