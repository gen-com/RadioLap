# RadioLap 와이어프레임

팀 라디오를 들으며 드라이버의 레이스 상황을 되짚는 앱의 화면 흐름과 배치를 확인하는 문서입니다. iOS 앱 구현에 앞서 합의한 3개 화면을 담았습니다.

## 열어보기

같은 폴더의 [와이어프레임](radio-lap.html)을 내려받아 Safari 또는 Chrome에서 여세요. Finder에서 HTML 파일을 더블 클릭해도 됩니다. GitHub의 파일 보기에서는 화면이 실행되지 않습니다.

Xcode 빌드, 로그인, API 키는 필요하지 않습니다. 브라우저에서 JavaScript를 허용해야 하며, 내보내기 도구의 공통 스타일·스크립트 일부는 외부 CDN을 사용하므로 인터넷 연결을 권장합니다. 레이스 데이터는 파일 안에 포함되어 있으며 OpenF1에 실시간 요청하지 않습니다.

## 화면 흐름

1. **레이스 목록**: 최신순으로 고정합니다. 이 미리보기에서는 싱가포르 GP만 열 수 있습니다.
2. **레이스 상세**: 레이스 정보와 결승 결과 순서의 드라이버 목록을 표시합니다. 순위가 없는 드라이버는 별도로 모읍니다.
3. **드라이버 라디오**: 선택한 드라이버의 공개 라디오 목록을 봅니다. Max의 라디오를 펼치면 재생 영역과 랩·순위·타이어 배치를 확인할 수 있습니다.

상단의 화면 이동 및 사례 버튼은 검토를 위한 도구이며, 앱에 넣기로 확정한 기능은 아닙니다.

## 확인할 사례

| 바로가기 | 확인 내용 |
| --- | --- |
| Max | 라디오 4개, 랩·순위·타이어, 최종 랩 완료 후 정보 |
| Stroll | 순위 없음, DNF, 라디오 없음 |
| Piastri | 결승 5위, 라디오 없음 |
| Albon | 결승 18위이면서 DNF |

- DNF는 미완주를 의미하며 순위 유무와 별도로 표시합니다.
- 순위가 없으면 임의의 숫자를 붙이지 않습니다.
- 공개 라디오가 없다는 것은 실제 교신이 없었다는 뜻이 아닙니다.
- Max 외에 라디오가 있는 드라이버는 개수와 안내만 표시하며, 세부 라디오 목록은 이 미리보기 범위에 포함하지 않았습니다.

## 데이터 기준과 연결 원칙

2026년 10월 13일 대화에서 확인한 OpenF1 응답을 반영한 고정 스냅샷입니다. 이후 API 결과가 바뀌어도 자동 갱신되지 않습니다. 이 폴더에는 당시 원본 API 응답 전체를 보관하지 않았습니다.

- 대상: 2026 싱가포르 GP 결승, `session_key=11388`, `meeting_key=1296`.
- 드라이버: 22명. 이 세션에서 Max의 `driver_number`는 `3`입니다.
- 출처: [OpenF1 문서](https://openf1.org/docs/). 레이스·세션, 드라이버, 세션 결과, 팀 라디오, 랩, 순위, 스틴트 데이터를 조합했습니다.
- 드라이버 목록은 결승 결과 순위이며, 라디오 카드의 순위는 라디오 기록 시각 이전의 마지막 순위 기록입니다.
- 랩은 라디오 기록 시각이 속한 랩 구간으로 연결하고, 타이어는 해당 랩을 포함하는 스틴트로 연결합니다.
- 표시 시간은 싱가포르 현지 시각입니다. API의 라디오 기록 시각과 실제 발화 시각은 다를 수 있습니다.
- Max의 마지막 라디오는 최종 랩 완료 후 약 76초의 기록입니다. 이 시점의 랩·타이어를 확정하지 않고 마지막 확인 정보로 표시합니다.
- 레이스 목록의 바레인 항목은 앞서 확인한 국가와 장소 정보가 일치하지 않아 장소 확인이 필요하다고 표시합니다.

## 구현 범위와 한계

이 파일은 화면 설계를 위한 모형입니다. 재생 버튼은 표시 상태만 바꾸며 실제 음성은 나오지 않습니다. 자동 대사 생성은 로딩 상태 예시만 보여주고, 음성 인식이나 번역을 수행하지 않습니다. OpenF1이 대사나 번역을 제공한다는 의미도 아닙니다.

네트워크 로딩·오류·재시도, 음성 재생 실패, 요청 순서 역전 방지 등은 이 와이어프레임에서 검증하지 않습니다. 이후 앱 설계와 구현 단계에서 다룰 항목입니다.

이 문서와 와이어프레임은 공개 API를 이용한 새 프로젝트의 설계 자료입니다. 회사 코드나 내부 자료를 포함하지 않습니다. iOS 앱 소스와 Xcode 프로젝트 설정에는 연결하지 않았습니다.

## 수정할 때

`radio-lap.html`은 일반 브라우저용 독립 HTML이며 화면 내용은 내부 iframe에 포함되어 있습니다. 화면이나 예시 데이터를 바꿀 때는 이 안내 문서의 범위·데이터 기준도 함께 갱신하세요. 상단 바로가기로 각 사례를 확인하고, 레이스 목록 → 레이스 상세 → 드라이버 라디오 → 뒤로 가기 흐름을 점검하세요.
