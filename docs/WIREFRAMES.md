# 팀 라디오와 당시 레이스 상황을 함께 살펴보기

## 교신만으로 알기 어려운 당시 상황을 연결합니다
팀 라디오는 레이스의 한순간을 담지만, 교신만으로는 당시 드라이버가 몇 랩을 달리고 있었는지, 몇 위였는지, 어떤 타이어를 사용했는지 알기 어렵습니다. 최종 경기 결과만으로도 그 순간의 상황을 설명하기는 어렵습니다.

RadioLap은 라디오와 흩어진 레이스 정보를 연결해, 사용자가 “어떤 상황에서 나온 교신인가”를 되짚을 수 있도록 합니다. 레이스와 드라이버를 고르고, 라디오를 들으며 기록 시각 주변의 랩·순위·타이어를 함께 살펴보는 경험을 목표로 합니다.

이 정보는 교신을 이해하는 단서입니다. 드라이버의 의도나 교신의 원인을 단정하지 않고, 데이터로 확인할 수 있는 상황을 보여줍니다.

## 와이어프레임에서 화면 흐름을 살펴보세요
[와이어프레임 바로 보기](https://gen-com.github.io/RadioLap/radio-lap.html)를 누르면 브라우저에서 화면 흐름을 살펴볼 수 있습니다.

**싱가포르 GP → Max Verstappen → 라디오 카드** 순서로 살펴보면 전체 흐름을 확인할 수 있습니다.

## 레이스를 고르고, 드라이버의 교신으로 들어갑니다
**레이스 목록 → 레이스 상세 → 드라이버 라디오** 순서로 탐색합니다.

| 화면 | 사용자가 하는 일 | 화면이 보여주는 정보 |
| --- | --- | --- |
| 레이스 목록 | 돌아볼 레이스를 고릅니다. | 최신순 레이스 목록과 날짜·장소 |
| 레이스 상세 | 경기 결과를 살펴보고 드라이버를 고릅니다. | 레이스 정보, 결승 순위와 미완주 여부 |
| 드라이버 라디오 | 교신 기록을 선택하고 당시 상황을 되짚습니다. | 공개 라디오 목록, 재생 영역과 랩·순위·타이어 |

## OpenF1 데이터를 교신의 맥락을 이해하는 정보로 연결합니다
OpenF1에서 얻는 정보를 각 화면의 목적에 맞게 연결합니다.

| 데이터 | 화면에서 전달하는 정보 |
| --- | --- |
| 대회·세션 | 어떤 레이스인지, 언제 어디서 열렸는지 |
| 드라이버·세션 결과 | 누가 참가했고 어떤 결과를 기록했는지 |
| 팀 라디오 | 어떤 드라이버의 교신이 언제 기록되었는지 |
| 랩·순위·스틴트 | 라디오 기록 시각에 연결되는 랩, 순위와 타이어 |

레이스 상세에서는 **최종 결과**를, 드라이버 라디오에서는 **교신 기록 시각 주변의 상황**을 보여줍니다. API 기록 시각은 실제 발화 시각과 다를 수 있으며, 확인할 수 없는 정보는 확정된 상태처럼 표시하지 않습니다.

현재 와이어프레임에는 이 구성을 보여주는 예시 데이터가 들어 있으며, OpenF1에 실시간 요청하지 않습니다. 화면에 포함된 모든 요소가 현재 앱의 구현 범위를 뜻하지는 않습니다.
